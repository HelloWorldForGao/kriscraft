
## Introduction 概述

Make the moss in Minecraft more useful! 让MC的苔藓变得更有用！

Added a lot of ITEMS,LOGICS,RECIPES AND ADVANCEMENTS about moss 添加了一系列苔藓相关物品、机制、配方、成就

## Added Items 添加内容（物品）

- Added Moss Bed,you can sleep without killing sheep 添加了苔藓床，用于在找不到羊的情况下睡觉
- Added Moss Bread,you can get more nutrition and saturation,and you will get a MOSS Mob Effect添加了苔藓面包，回复更多饱食和饱和，同时给予“苔藓”效果
- Added Moss Bread,you can get MORE nutrition and saturation,and you will get a BURGER Mob Effect添加了苔藓汉堡，相比于苔藓面包更上一层楼，同时给予“汉堡”效果

## Added Logics 添加内容（机制）

- Now you can use moss directly (Not eating,no animation),and the placing of the moss won't be effected 现在你可以直接使用苔藓方块（不是食用，没有食用动画），当然苔藓的放下不受影响
- You can also eat moss block on the ground now 现在你也可以吃放下来的苔藓方块

## Added recipes 添加内容（配方）

- 3 Moss Block + 3 Any plank(shaped) => Moss Bed 使用3苔藓块+3任意木板（有序合成）合成苔藓床
- 1 Moss Block + 8 Bread(shapeless) => 8 Moss Bread 使用1苔藓块+8面包（无序合成）合成8个苔藓面包
- 2 Moss Bread + 1 Any meat => Moss Burger 使用2苔藓面包+1任意肉（无序合成）合成1个苔藓汉堡

## Added Advencements 添加内容（成就）

- Get advancement by using Moss Block (4 in total) 使用苔藓方块可获得成就（共计4个）
- Get advancement by sleeping on Moss Bed (4 in total) 在苔藓床上睡觉可获得成就（共计4个）
- Get advancement by eating Moss Bread (4 in total) 使用苔藓面包可获得成就（共计4个）

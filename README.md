
## Introduction 概述

Make the moss in Minecraft more useful! 让MC的苔藓变得更有用！

Added a lot of ITEMS,LOGICS,RECIPES,ADVANCEMENTS AND UI about moss 添加了一系列苔藓相关物品、机制、配方、成就、UI

## Added Items 添加内容（物品）

- Added Moss Bed,you can sleep without killing sheep 添加了苔藓床，用于在找不到羊的情况下睡觉
- Added Moss Bread,you can get more nutrition and saturation,and you will get a MOSS Mob Effect 添加了苔藓面包，回复更多饱食和饱和，同时给予“苔藓”效果
- Added Moss Bread,you can get MORE nutrition and saturation,and you will get a BURGER Mob Effect 添加了苔藓汉堡，相比于苔藓面包更上一层楼，同时给予“汉堡”效果

## Added Logics 添加内容（机制）

- Now you can use moss directly (Not eating,no animation),and the placing of the moss won't be effected 现在你可以直接使用苔藓方块（不是食用，没有食用动画），当然苔藓的放下不受影响
- You can also eat moss block on the ground now 现在你也可以吃放下来的苔藓方块

## Added recipes 添加内容（配方）

- 3 Moss Block + 3 Any plank => Moss Bed 3苔藓块+3任意木板 => 苔藓床
- 1 Moss Block + 8 Bread => 8 Moss Bread 1苔藓块+8面包 -> 8个苔藓面包
- 2 Moss Bread + 1 Any meat => Moss Burger 2苔藓面包+1任意肉 => 1个苔藓汉堡

## Added advancements 添加内容（成就）

- Get the advancement "KrisCraft" by eating the moss 通过吃苔藓获得成就“Kris工艺”
- You can also get advancement by sleeping on the moss bed,eating moss bread and eating moss burger 在苔藓床上睡觉、吃苔藓面包和苔藓汉堡都有成就

## Added UI 添加内容（UI）

- Added a configure page,open by using key or ModMenu 多出了一个配置页面，可以通过快捷键或ModMenu打开
- Operate like in the Deltarune! 像在Deltarune里一样操作！

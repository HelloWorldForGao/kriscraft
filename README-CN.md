# Kris工艺
## 概述

让MC的苔藓变得更有用！添加了一系列苔藓相关物品、机制、配方、成就、UI、指令

## 添加内容（物品）

- 添加了苔藓床，用于在找不到羊的情况下睡觉
- 添加了苔藓面包，回复更多饱食和饱和，同时给予“苔藓”效果
- 添加了苔藓汉堡，相比于苔藓面包更上一层楼，同时给予“汉堡”效果

## 添加内容（机制）

- 现在你可以直接使用苔藓（不是食用，没有食用动画），当然苔藓的放下不受影响
- 现在你也可以吃放下来的苔藓方块

## 添加内容（配方）

- 3苔藓+3木板（有序合成） => 苔藓床[^1]
- 1苔藓+8面包（无序合成） => 8个苔藓面包
- 2面包+1任意肉（无序合成） => 1个苔藓汉堡[^2]

## 添加内容（成就）

- 通过吃苔藓获得成就“Kris工艺”
- 在苔藓床上睡觉、吃苔藓面包和苔藓汉堡都有成就

## 添加内容（UI）

- 多出了一个配置页面，可以通过快捷键或ModMenu打开
- 像在Deltarune里一样操作！[^3]
- 使用右shift退出以同步你的更改到服务器（只要你有那个权限）
- 使用esc退出将只在本地保存

## 添加内容（指令）

- `/kriscraft config <name> <value>` : 仅供调试，正常玩家和管理勿用
- `/proceed` : 致命，可以试试

## 配置项

- 所有配置项在`/游戏根目录/config/kriscraft.json`中存储
- 可以使用`/kriscraft config <配置项> <值>`来修改,目前没有自动提示
- can_eat_moss : 是否可以吃苔藓（物品），仅当开启此项且未按shift时生效
- can_eat_moss_block : 是否可以吃苔藓（方块），仅当开启此项且未按shift时生效
- moss_heal : 吃一个苔藓可以恢复多少
- moss_product_heal_base_scale : 吃苔藓制品的回复倍率，苔藓面包的每刻（1秒20刻）回复（？）量为$moss\_heal * moss\_product\_heal\_base\_scale * 0.1$[^4]

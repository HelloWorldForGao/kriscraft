
## 概述

让MC的苔藓变得更有用！添加了一系列苔藓相关物品、机制、配方、成就

## 添加内容（物品）

- 添加了苔藓床，用于在找不到羊的情况下睡觉
- 添加了苔藓面包，回复更多饱食和饱和，同时给予“苔藓”效果
- 添加了苔藓汉堡，相比于苔藓面包更上一层楼，同时给予“汉堡”效果

## 添加内容（机制）

- 现在你可以直接使用苔藓（不是食用，没有食用动画），当然苔藓的放下不受影响
- 现在你也可以吃放下来的苔藓方块

## 添加内容（配方）

- 使用3苔藓+3木板（有序合成）合成苔藓床
- 使用1苔藓+8面包（无序合成）合成8个苔藓面包
- 使用2面包+1任意肉（无序合成）合成1个苔藓汉堡

## 添加内容（成就）

- 使用苔藓方块可获得成就（共计4个）
- 在苔藓床上睡觉可获得成就（共计4个）
- 使用苔藓面包可获得成就（共计4个）

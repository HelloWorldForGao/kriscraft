## 概述

让MC的苔藓变得更有用！添加了一系列苔藓相关物品、机制、配方、成就、UI

## 添加内容（物品）

- 添加了苔藓床，用于在找不到羊的情况下睡觉
- 添加了苔藓面包，回复更多饱食和饱和，同时给予“苔藓”效果
- 添加了苔藓汉堡，相比于苔藓面包更上一层楼，同时给予“汉堡”效果

## 添加内容（机制）

- 现在你可以直接使用苔藓（不是食用，没有食用动画），当然苔藓的放下不受影响
- 现在你也可以吃放下来的苔藓方块

## 添加内容（配方）

- 3苔藓+3木板 => 苔藓床
- 1苔藓+8面包 => 8个苔藓面包
- 2面包+1任意肉 => 1个苔藓汉堡

## 添加内容（成就）

- 通过吃苔藓获得成就“Kris工艺”
- 在苔藓床上睡觉、吃苔藓面包和苔藓汉堡都有成就

## 添加内容（UI）

- 多出了一个配置页面，可以通过快捷键或ModMenu打开
- 像在Deltarune里一样操作！
- 使用shift退出以同步你的更改到服务器（只要你有那个权限）
- 使用esc退出将只在本地保存
